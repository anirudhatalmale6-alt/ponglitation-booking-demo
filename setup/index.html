2 Create your hosting (free)

≈ 10 minutes · free to start
  1. Go to render.com and click Get Started. Sign up with your email or Google (it's free).
  2. On your dashboard, click New + (top right) → Web Service.
  3. Choose “Public Git Repository” and paste this into the box:
    https://github.com/anirudhatalmale6-alt/ponglitation-booking-demo
    then click Connect.
  4. It'll show a settings form. Fill it in exactly like this:
    Nameponglitation
    Root Directorybackend
    Build Commandnpm install
    Start Commandnpm start
    Instance TypeFree
  5. Scroll down to Environment Variables → click Add Environment Variable and enter:
    KeyADMIN_PASSWORD
    Valuea password you choose (this logs you into your dashboard — pick something you'll remember)
  6. Click Create Web Service at the bottom. Give it 2–3 minutes to build — you'll see logs scroll, then “Live”. 🎉
At the top of that page you'll see your new web address — it looks like https://ponglitation.onrender.com. That's your live site! Copy that link.
